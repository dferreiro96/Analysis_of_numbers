# Number Analysis / Análisis de Números

A Python CLI program to analyze a list of numbers: find the largest, smallest, average, even count, and odd count.

Un programa de línea de comandos en Python para analizar una lista de números: encontrar el mayor, menor, promedio, cantidad de pares y cantidad de impares.

## Features / Funcionalidades

- Add numbers to a list / Añadir números a una lista
- List all numbers sorted / Listar todos los números ordenados
- Find the largest number / Encontrar el mayor número
- Find the smallest number / Encontrar el menor número
- Calculate the average / Calcular el promedio
- Count even numbers / Contar números pares
- Count odd numbers / Contar números impares
- Menu-driven interface / Interfaz con menú
- Input validation with `try/except` / Validación de entrada con `try/except`

## Requirements / Requisitos

- Python 3
